# 九宫格 `.9.png` 制作工具

这是一个无依赖、纯前端的 Android 9-patch 图片制作工具。图片不会上传到网络，所有读取、预览和导出都在浏览器内完成。

## 运行方式

- 直接双击打开 `index.html`；或
- 在当前目录启动任意静态服务器，例如：

  ```bash
  python -m http.server 8080
  ```

  然后访问 <http://localhost:8080>。

## 使用说明

页面顶部的“使用说明”按钮可打开简要操作弹窗；页面同时提供 `favicon.svg` 图标，收藏页面或创建桌面快捷方式时可用于识别本工具。

1. 将 PNG、JPG、WebP 图片直接拖入中间的编辑画布；拖入时会出现高亮提示。
2. 在编辑画布中拖动红色线调整拉伸区域、蓝色线调整内容区域；也可以在左侧输入像素值。
3. 右侧实时预览按当前标记实时渲染九宫格效果；勾选醒目的“文案预览”后，会在当前蓝色内容区域内显示一组完整示例语句，并根据内容区域宽高自动换行、缩放和居中，方便确认内容边界和观察拉伸效果。拖动或输入内容边界后会立即更新。该文案只用于预览，不会写入导出文件。
4. 根据使用场景选择四种独立导出：
   - **导出原始 `.9.png`**：单图保留外围 1px 黑色标记，文件名为 `${基础名}-raw.9.png`，适合交给 `aapt/aapt2`。
   - **导出编译 `.compiled.9.png`**：单图裁掉可见标记线并写入 Android `npTc` chunk，文件名为 `${基础名}-compiled.9.png`。
   - **导出原始 ZIP**：文件名为 `${基础名}-raw.zip`，ZIP 内仅包含一个 `${基础名}-raw.9.png` 原始标记版文件。
   - **导出编译 ZIP**：文件名为 `${基础名}-compiled.zip`，ZIP 内仅包含一个 `${基础名}-compiled.9.png` 编译 `npTc` 文件。

两个 ZIP 在浏览器本地独立生成，不合并两个图片、不上传图片，也不包含额外密度目录，避免导出包过大。

如果 Windows 安全中心因 Internet 安全设置（Mark-of-the-Web）阻止 ZIP 打开：右键下载的 ZIP，选择“属性”，在底部勾选或点击“解除锁定”，点击“应用”后再解压；也可以先将 ZIP 复制到本地工作目录再使用资源管理器或 PowerShell 解压。ZIP 本身使用无压缩（stored method 0）、标准 CRC32、UTF-8 文件名和非 ZIP64 结构生成。

基础名来自导入文件名：去掉原扩展名以及已有的 `.9`、`.raw.9`、`.compiled.9`、`-raw.9` 或 `-compiled.9` 后再追加后缀；非法文件名字符会替换为下划线，中文名称会保留。例如 `button.png`、`button.9.png` 和 `button-raw.9.png` 都导出为 `button-raw.9.png`、`button-compiled.9.png`、`button-raw.zip`、`button-compiled.zip`。

原始导出的尺寸为原图宽高各增加 2px：原图位于 `(1, 1)`，黑色标记仅写入外围 1px，内容区边框保持透明。编译导出的可见尺寸为原图尺寸，标记通过 `npTc` chunk 保存。此纯前端工具不上传图片，也不依赖或调用本机 `aapt`。
